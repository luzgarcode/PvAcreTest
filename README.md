# PV & Go

Outil interne pour remplir les PV d'installation Acrelec sur le terrain (mobile) et generer le PDF rempli.

- `index.html` : l'application (page unique, se lit directement dans un navigateur).
- `models/` : les modeles de PV disponibles (recuperes automatiquement par l'appli au chargement).

Ne pas modifier `models/` a la main : les fichiers sont generes et mis a jour automatiquement.
